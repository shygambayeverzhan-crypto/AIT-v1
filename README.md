# AI Targetologist — backend

Настоящий сервер: проксирует запросы к Claude (ключ API хранится только
здесь), считает лимиты бесплатных запусков на каждого посетителя, принимает
заявки на оплату и даёт вам, владельцу, панель подтверждения — вход по коду,
который проверяется на сервере, а не в браузере.

## Что внутри

- `server.js` — весь backend на Express + SQLite (один файл `data.sqlite`,
  ничего дополнительно устанавливать не нужно).
- `public/index.html` — фронтенд. Отдаётся тем же сервером, обращается к
  API по относительным путям (`/api/...`).
- `.env.example` — шаблон настроек. Скопируйте в `.env` и впишите свои
  значения.

## Запуск локально (проверить, что всё работает)

```bash
cd backend
npm install
cp .env.example .env
# откройте .env и впишите:
#   ANTHROPIC_API_KEY=ваш_ключ_с_console.anthropic.com
#   ADMIN_CODE=свой_код (например Yerzhan_2005_что-то-своё)
npm start
```

Откройте `http://localhost:3000` — увидите сайт. Кнопка «Вход владельца»
внизу страницы — там вводится `ADMIN_CODE` из `.env`.

## Как это работает

- **Обычный посетитель** ничего не устанавливает и никуда не логинится:
  при первом визите браузер сам создаёт случайный ID и кладёт его в
  `localStorage`. Все лимиты и тариф привязаны к этому ID на сервере
  (таблица `clients` в `data.sqlite`).
- **Оплата** — посетитель жмёт «Я оплатил», это создаёт запись в таблице
  `requests` со статусом `pending`. Тариф при этом **не включается**.
- **Вы подтверждаете** — заходите на сайт, жмёте «Вход владельца», вводите
  код из `.env`. Появляется вкладка «Админ» со списком заявок и кнопками
  «Подтвердить» / «Отклонить». Подтверждение — это единственное действие,
  которое реально меняет тариф клиента.
- Код администратора проверяется в `server.js` (`requireAdmin`), а не в
  `index.html` — значит его не видно через «Просмотр кода страницы».

## Куда задеплоить (чтобы было доступно всем в интернете)

Любой из вариантов ниже подходит, отличаются только деталями:

1. **Render.com** (проще всего для новичка)
   - Зарегистрируйтесь, "New Web Service" → подключите репозиторий с этой
     папкой (или загрузите вручную через Render's Git-деплой).
   - Build command: `npm install`
   - Start command: `npm start`
   - В разделе Environment добавьте `ANTHROPIC_API_KEY` и `ADMIN_CODE`.
   - Render выдаст адрес вида `https://ваш-проект.onrender.com` — это и
     есть публичная ссылка для всех.

2. **Railway.app** — то же самое, ещё немного проще интерфейс.

3. **Свой VPS** (если уже есть сервер) — поставить Node.js 18+,
   `npm install`, `npm start` (лучше через `pm2` или `systemd`, чтобы
   сервер не падал при перезагрузке), сверху Nginx с вашим доменом.

После деплоя привяжите свой домен в настройках хостинга — тогда ссылка
будет вида `https://ваш-домен.kz`, а не служебный поддомен.

## Важно перед реальным запуском

- **`data.sqlite` должен жить на постоянном диске.** На бесплатных тарифах
  некоторых хостингов файловая система пересоздаётся при каждом деплое —
  тогда база обнулится. Уточните у хостинга про "persistent disk" или
  переходите на управляемую БД (Postgres), если это критично.
- **`ADMIN_CODE` — придумайте длинный и не публикуйте его** — это
  единственная защита панели.
- **Проверка оплаты по-прежнему ручная** — сервер не подключён к Kaspi API,
  он просто хранит "клиент нажал кнопку, я оплатил". Реальную проверку
  делаете вы через WhatsApp/Kaspi, как и раньше.
- **Стоимость Anthropic API** — оплачивается по токенам, отдельно от
  хостинга. Проверьте баланс в console.anthropic.com.
